# About zeph
✨ A minimalist scripting language for embedded systems &amp; rapid prototyping
💬 You can read it.Its pronunciation is /z3:f/

## Advanced
|⚡ C-like syntax | 🚀 &lt;1MB runtime | 📚 MIT Licensed | 🐧 Cross-platform (Win/Linux/macOS)|
|:---------------:|:------------------:|:---------------:|:-----------------------------------:|

|             C Interop             |               Portable               |            Modern Tooling            |              Educational              |
|:---------------------------------:|:------------------------------------:|:-----------------------------------:|:---------------------------------------:|

A minimalist scripting language designed for **embedded systems** and **rapid prototyping**, delivering C-like performance with Python-like simplicity.

